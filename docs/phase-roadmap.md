## 우선순위 원칙

1. **쿠팡 깊이 우선** — 멀티마켓 확장보다 쿠팡 운영(주문·매입·정산) 완성도 먼저
2. **자동화 우선** — 반복 작업(필수항목/재고/이름)은 스크립트·크론으로
3. **본업 잔재는 무해하면 방치, 안정화 후 점진 제거** — DB 객체는 공유라 제거 금지
