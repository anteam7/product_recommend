# 출처 → 페르소나 매핑 사전 (source-persona-map)

> 트렌드 레이더가 수집하는 `jimscanner_trends_aliases.source` 값을
> **인구집단(페르소나)** 으로 해석하는 단서 사전.
> 코드 진실원본은 `src/app/admin/(dashboard)/trend-radar/audience/page.tsx`
> 의 `SOURCE_PERSONA` 상수이며, 이 문서는 그 근거·운영 의도를 설명한다.

## 왜 필요한가

지난주 커뮤니티 소스가 대량 수집됐지만(82cook 198 · natepan 160 ·
ppomppu 127 · musinsa 132 · dcinside 60), 상품 점수로 뭉뚱그려지면서
**"어느 집단에서 떴는가"** 라는 출처 자체의 인구학적 신호가 버려졌다.
출처=집단 신호는 위탁 셀러가 **타겟·소구 앵글·광고 채널**을 무료로 정하는
핵심 단서다. 이 보드는 상품별 source set 을 페르소나로 역추정한다.

> 새 수집 소스가 생기면 위 표와 `SOURCE_PERSONA` 상수에 함께 추가할 것.

## 보드 분류 로직

상품별로 source 의 등장 횟수(cnt)를 페르소나 키로 합산한 뒤:

- **타겟 명확형**: 최상위 페르소나 비중 ≥ 60% 이고 페르소나 종류 ≤ 2.
  → 단일 집단에 집중. 그 집단의 소구 앵글·채널로 바로 공략.
- **광범위형**: 그 외(여러 집단에 분산 출현).
  → 대중 수요. 네이버쇼핑·쿠팡 등 범용 채널 + 다소구 A/B.

## 한계

- source 는 alias 수집 시점의 출처일 뿐, 실제 구매자 집단의 확정 정보는 아니다.
  (검색 트렌드 계열은 인구학 신호가 약해 의도적으로 '검색 실수요'로 묶음.)
- 페르소나 가중치는 cnt(출처별 alias 등장 횟수) 기반의 휴리스틱이다.
